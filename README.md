![platform](https://img.shields.io/badge/platform-Windows%2010%2F11%20x64-informational)
![.NET](https://img.shields.io/badge/.NET-8.0-512BD4)
![license](https://img.shields.io/badge/license-Apache%202.0-blue)

[![Release](https://img.shields.io/github/v/release/8008lover69/XRAYCLIENT-69?label=Release)](https://github.com/8008lover69/XRAYCLIENT-69/releases)

Оболочка поверх [xray-core](https://github.com/XTLS/Xray-core) для импорта
пользовательских конфигураций и подписок (по ссылке или QR-коду) и
локального проксирования трафика. Сама программа не является VPN-сервисом
и не продаёт сервера — только клиент для конфигураций, которые уже есть у
пользователя.

## Установка

Скачайте [`XrayClient-Setup.exe`](https://github.com/8008lover69/XRAYCLIENT-69/releases/latest)
из раздела **Releases** и запустите его.

- Установка не требует прав администратора (в `%LocalAppData%\Programs\XrayClient`).
- Внутри — полностью автономный (self-contained) билд: .NET 8 Runtime и
  `xray-bridge.dll` уже включены, ничего дополнительно ставить не нужно.
- Мастер на русском языке, создаёт ярлык в меню «Пуск» (и по желанию —
  на рабочем столе) и запускает приложение по завершении.
- Деинсталляция через «Установка и удаление программ» полностью удаляет
  приложение и его данные (`%AppData%\XrayClient`).

## Возможности

- Импорт по ссылке-подписке (URL) с автообновлением по расписанию, либо
  вручную кнопкой «Обновить подписки».
- Импорт одиночных ссылок `vless://`, `vmess://`, `trojan://`, `ss://`,
  `socks://` — вставкой текста, из QR-картинки или сканированием QR прямо
  с экрана.
- Пинг всех серверов и автовыбор самого быстрого (разовая проверка, кнопка
  «Автовыбор лучшего»).
- **Умный автовыбор** (в «Настройках»): при подключении используются сразу
  все серверы из списка — xray-core (через встроенные `observatory` +
  `leastLoad`-балансировщик) сам постоянно проверяет их по RTT и держит
  трафик на самом быстром живом сервере, автоматически переключаясь без
  переподключения из приложения, если текущий отвалится.
- Тёмная и светлая тема (переключается в «Настройках», применяется сразу
  ко всем элементам интерфейса, включая скроллбары).
- Трей-иконка со статусом подключения; закрытие окна сворачивает в трей.
- Счётчик трафика (скорость и суммарный объём) по активному подключению.
- Поддержка SIP003-плагинов Shadowsocks (`v2ray-plugin`, `obfs-local` и т.п.).

## Юридическая заметка

Программа — универсальный клиент-оболочка для протоколов, которые сами по
себе легальны и широко используются (в том числе корпоративными VPN,
CDN-обходом блокировок, разработкой и т.д.). Ответственность за то, какие
конфигурации/сервера пользователь в неё загружает и как использует, лежит
на пользователе — так же, как и с любым другим общецелевым сетевым
клиентом (curl, browser, ssh-клиент и т.п.).
